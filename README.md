# xiaochengxu
asmallpragramming

白色与蓝色的手机个人记录 PWA。每日任务和每日随记按北京时间归档；数据只写入当前浏览器的 IndexedDB，无后端、无统计追踪、无 CDN。正文作为纯文本显示。

## 本地预览

安装 Node.js 22 或更新版本，在本目录运行 `node tools/serve.mjs`，打开 http://127.0.0.1:4173/xiaochengxu/ 。运行 `npm test` 执行数据验证测试。首次打开前需要生成图标的情况下，执行 `node tools/icons.mjs`（项目已附 PNG）。直接双击 HTML 不支持完整 PWA。

## 发布到 GitHub Pages

1. 使用你的仓库 [jutao402/xiaochengxu](https://github.com/jutao402/xiaochengxu)。免费账户可使用公开仓库；仓库内只有程序，不包含记录。普通 Pages 网站可公开访问，别人访问时使用他们自己的设备数据库。
2. 将本目录中的所有文件（包括 `.github` 目录）提交至仓库根目录、分支 `main`；不是把整个 `personal-daily` 文件夹嵌套上传。
3. 仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。
4. 在 Actions 查看 Publish daily PWA。若初次推送时还未配置 Pages，配置后手动 Run workflow 或重新运行任务。
5. 任务成功后，在 Settings → Pages 获取 `https://jutao402.github.io/xiaochengxu/` 地址。这个地址只有部署成功后才可用。
6. 用华为手机浏览器打开。GitHub Pages 在你的网络上是否顺畅需要实测；首次打开等待离线缓存就绪。

参考：[GitHub Actions 发布说明](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## 华为 Pura 70 / HarmonyOS 4.2

先在华为浏览器普通模式打开网址，新增一条测试任务，刷新检查，然后在数据与设置中检查“离线缓存已就绪”。浏览器菜单中查找“添加到桌面”或类似选项；如果没有，就保存书签。完整 PWA 安装、存储持久化、文件下载由实际浏览器支持情况决定。

添加桌面后，固定从该入口使用，先验证记录是否存在；不同浏览器、隐私模式、桌面独立应用可能拥有不同的存储空间。离线缓存就绪后切断网络，重新打开并编辑记录，确认可用。电脑无需持续开机。

## 数据及备份

- `tasks`：id、日期、内容、完成状态、创建时间、修改时间。
- `notes`：日期（每天一篇）、正文、创建时间、修改时间。
- `meta`：首次使用时间及最近发起导出时间。没有上传到 GitHub 或云数据库。数据库名包含应用路径，避免同域其他副本意外混用；同域网页仍属于同一浏览器安全边界。
- 任务即时写入；随记停止输入约 1 秒后写入，数据库事务完成后才显示“已保存”。切换日期及用户主动更新时会先保存草稿。若强制终止浏览器或关机，未完成保存的输入可能丢失，请确认保存状态。
- 页面隐藏时尽力保存，但移动系统不保证给后台网页执行时间。立即保存按钮可在离开前主动保存。
- 发起使用满一周后提醒导出；发起导出会重置提醒，网页无法验证你是否最终保留文件。
- 在数据与设置中导出完整 JSON，手动存到手机“文件”、另一设备或可信网盘。仅在同一手机内部保留副本不能防止丢手机。
- 导入先验证版本、字段、日期和重复编号，再预览。文件上限 30 MB。合并按任务 id / 随记日期去重，修改时间较新者胜出；时间相同保留当前版本。不同 id 的相同标题任务不会被误合并。合并不传播之前的删除操作。
- 每次导入前发起当前数据备份下载，需要用户确认文件保存。恢复完整替换当前任务和随记，在一个事务中完成；失败回滚。备份无历史版本撤销功能。
- Markdown 导出为阅读用途；还原数据请使用完整 JSON。
- 清除网站数据、浏览器卸载、换手机、浏览器自动回收存储都可能导致丢失。申请持久化存储不能防止主动清除；必须另存备份。
- 使用固定域名和项目路径。更换域名或项目路径需要先导出再导入。数据未加密，能解锁手机并访问该浏览器的人可能读取记录。

## 更新维护

修改静态文件时递增 `sw.js` 的缓存版本。缓存名称包含应用路径，避免同一 GitHub 用户的其他项目互相清理缓存。新 service worker 不会自动强制刷新；点击保存并更新时先保存任务草稿和随记。数据库版本升级必须在 `db.js` 增加向前迁移，不能删除对象仓库或清空数据。新增数据格式时同步更新备份校验和版本迁移策略。

## 测试

`npm test`：北京时间、日期有效性、备份格式、往返、冲突合并与重复导入。

`node tests/browser.mjs`：需要可用的 Playwright 和 Chromium；可通过 `PLAYWRIGHT_MODULE` 指定 Playwright 模块路径，`BROWSER_EXECUTABLE` 指定已有 Chrome 或 Edge。测试在独立临时浏览器上下文中创建合成记录，检查手机布局、IndexedDB、离线、备份恢复、写入失败和应用更新。真实华为手机仍需上述现场验证。
